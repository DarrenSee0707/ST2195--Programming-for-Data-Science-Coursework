# ST2195--Programming-for-Data-Science-Coursework
Coursework project for ST2195 using R and Python to analyse U.S. flight delays, traffic patterns, cascading airport disruptions, and predictive delay models.

The project uses a subset of the 2009 ASA Statistical Computing and Graphics Data Expo flight dataset to explore key questions about airline performance and delays in the United States.

The analysis covers:

•identifying the best time of day, day of week, and season to fly in order to minimise delays
•examining whether older planes experience more delays
•analysing how passenger traffic between locations changes over time
•investigating possible cascading failures across airports where delays propagate through the network
•building a predictive model for flight delays using available variables

This repository includes:

•RMarkdown files for the R-based analysis
•Jupyter notebooks for the Python-based analysis
•supporting code for data cleaning, wrangling, visualisation, and modelling
•and the final report summarising methods, results, and interpretations
